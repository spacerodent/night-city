# Night City

A dark, moody cyberpunk theme for [Omarchy](https://omarchy.org/): deep midnight navy, cyan accents, violet neon and red-LED alerts.

![Night City preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/spacerodent/night-city
```

That's it: the install applies the theme and its wallpaper automatically.

## Palette

| Role | Color |
|------|-------|
| Background | `#0a0d1a` |
| Foreground | `#c9cdf2` |
| Accent (cyan) | `#35e0f0` |
| Magenta (violet neon) | `#c04dff` |
| Red (LED) | `#ff3b4e` |
| Green | `#5ef2b0` |
| Blue | `#6c8cff` |

All colors live in `colors.toml`; Omarchy generates the bar, terminal, and app themes from it.

## Wallpaper

The included wallpaper (`backgrounds/1-night-city.jpg`, 1376×768) was generated with Gemini. Add your own images to `backgrounds/` and cycle with `omarchy theme bg next`.
